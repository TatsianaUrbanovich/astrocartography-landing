# Астрокартография — лендинг

Одностраничный лендинг проекта «Астрокартография» — инструмента выбора места
для жизни и работы по натальной карте.

Страница: https://tatsianaurbanovich.github.io/astrocartography-landing/

## Что это

Статическая страница в одном файле: стили и скрипт внутри `index.html`,
внешних библиотек нет. Двуязычная — русский по умолчанию, переключатель RU/EN
в шапке, выбор сохраняется в браузере.

Карта мира в секции «решение» — inline SVG. Контуры континентов и положения
городов посчитаны в равнопромежуточной цилиндрической проекции, поэтому
Лиссабон действительно лежит на меридиане Юпитера, Берлин — на меридиане
Сатурна, Барселона — на кривой Венеры.

## Как открыть локально

Достаточно открыть `index.html` в браузере — сборка и сервер не нужны.

## Статус

Продукт в разработке. Страница существует, чтобы объяснить идею и собрать
отклики.
